# Nerd Fonts

This is an archived font from a Nerd Fonts release (JetBrainsMono).

For more information see:
* https://github.com/ryanoasis/nerd-fonts/
* https://github.com/ryanoasis/nerd-fonts/releases/latest/
* Upstream (unpatched) JetBrains Mono: https://github.com/JetBrains/JetBrainsMono

Includes both the `JetBrainsMono` and `JetBrainsMonoNL` (no ligatures) variants, each in
`Nerd Font` (proportional-icons), `Nerd Font Mono` (icons forced monospace), and
`Nerd Font Propo` (proportional) flavors, across all weights.
